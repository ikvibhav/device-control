# Problem Components

### Coordinate Systems

- **PU_CS (Positioning Unit Coordinate System)**: Fixed reference frame for the position unit
- **WAFER_CS (Wafer Coordinate System)**: Local coordinate system relative to wafer center

### Key Components

1. **Positioning Unit (PU)**: Arm that moves the measuring device
2. **Measuring Device (MD)**: Sensor mounted on PU with known offset
3. **Wafer**: Object being measured, contains shots with alignment marks (grids)
4. **Calibration Station**: Reference point for MD offset calibration
